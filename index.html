Privacy

Uploaded genomes are sensitive. File names are not kept. Your reads are deleted from the server as soon as the run ends; only the results (variant calls, annotations, evidence, report) are kept, and are deleted 7 days after upload. Anyone with this page's link can read the results, so do not share it. Logs contain job ids, states and sizes only, never sequence content.
